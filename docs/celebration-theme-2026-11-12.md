# Peach and coral celebration theme

User-selected bright peach/coral palette for Jashntoons. Public pages use warm paper, peach section surfaces, coral actions and dark brown text. Creation/editor tools and full-screen viewing keep warm charcoal surfaces with peach controls. No media or invitation render data is recoloured.

- Shared semantic colours in app/celebration-theme.css, loaded after component styles.
- Homepage, collections, package comparison, account library, format chooser, mobile navigation, guide/reel-room and privacy/terms pages use the public palette.
- Existing cinematic UI styles replace their olive cast with warm neutrals and peach; layouts, scene timing, credits and generation logic are unchanged.
- Contrast checks: body 12.93:1; secondary text on peach 4.88:1; primary action 5.43:1; coral label on peach 4.54:1; studio secondary text 7.60:1.
- CSS parsing and existing selector/declaration structure checks passed.
- Visual review: desktop hero, packages/custom package, saved library, creation chooser and creation workspace; phone 393x852 hero, collection, menu and full-screen playing reel.

Local preview uses existing QA fixtures; its saved-video endpoint error is not a production or generation verification. No paid generation or live data changes were performed for colour QA.
